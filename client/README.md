# HTML and CSS Assignment  (Stay&Play)

## Overview

This project is an HTML and CSS based web page created as part of the **HTML and CSS Assignment**.

The assignment focuses on implementing a responsive and visually structured webpage using **HTML5** and **CSS3**, including different sections, layouts, cards, navigation elements, forms, and a responsive footer.

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* CSS Media Queries
* SVG

## Features

* Responsive navigation section
* Hero section
* Responsive card-based layouts
* Content and recommendation sections
* Guest review section
* Booking section
* Responsive forms and select elements
* Social media icons using SVG
* Responsive footer
* Mobile, tablet, and desktop layouts

## Responsive Design and Breakpoints

The webpage is designed to work across different screen sizes:

* Desktop :  greater than and equal to 1024px
* Laptop  :  greater than and equal to 1024px
* Tablet    :  greater than 767px & less than 1024px
* Mobile   :  less than 767px

CSS media queries are used to adjust layouts, card columns, spacing, sizing, and other elements according to the screen width.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
